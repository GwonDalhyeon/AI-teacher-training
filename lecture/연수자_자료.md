# ChatGPT를 이용한 수업 조언자 만들기

**오늘 목표**: 내 수업 상황을 아는 AI 수업 조언자 프로젝트를 직접 완성합니다.

이 연수는 하루 12시간 연수의 두 번째 블록입니다.

| 블록 | 내용 | 시간 |
|:-----|:-----|:-----|
| 1부 | AI 활용 개론 | 앞 3시간 |
| **2부 (지금)** | **ChatGPT 수업 조언자 만들기** | **이 3시간** |
| 3부 | AI 수업 준비·활용 심화 | 뒤 6시간 |

뒤 강의는 오늘 만든 조언자를 이미 갖고 있다는 전제로 진행됩니다.
오늘 완성하지 않으면 뒤 강의에서 출발선이 달라집니다.

---

## 1. 수업 조언자란?

### 일반 AI 채팅과 무엇이 다른가

| 구분 | 일반 AI 채팅 | 수업 조언자 프로젝트 |
|:-----|:------------|:----------------|
| 교과·학급 정보 | 매번 새로 설명 | 한 번 설정하면 유지 |
| AI 행동 방식 | 무엇이든 대답 | 설계된 원칙대로 작동 |
| 대화 맥락 | 창 닫으면 사라짐 | 프로젝트 안에 축적 |
| 내 수업 철학 | 반영 안 됨 | 처음부터 알고 있음 |

### Layer 구조: 두 가지를 설정한다

**Layer 1 — 조언자의 행동 원칙** (이미 완성됨, 오늘 붙여넣기만 하면 됨)

이 조언자가 어떻게 행동할지를 정하는 규칙 문서입니다. "교사의 판단을 대체하지 않고 질문자·보완자·점검자로 행동한다", "기준 문서를 수호한다" 같은 원칙들이 담겨 있습니다.

**Layer 2 — 내 맥락 계약** (오늘 함께 만드는 것)

조언자가 나를 알기 위한 정보입니다: 내 교과와 학교급, 수업 철학, 학급 상황, 조언자에게 기대하는 역할.

Layer 2는 오늘 조언자와 대화를 통해 함께 작성합니다. 조언자가 질문을 하면 내가 답하는 방식으로 진행됩니다.

## 2. 내 AI 선택하기

오늘 실습은 ChatGPT 기준으로 진행합니다. 다른 AI를 사용하거나 ChatGPT 무료 한도가 찼을 때도 동일하게 구성할 수 있습니다.

| 플랫폼 | ChatGPT | Gemini Gems | Claude Projects |
|:-------|:--------|:------------|:----------------|
| 접속 주소 | chatgpt.com | gemini.google.com | claude.ai |
| 무료 한도 | 있음 | 넉넉함 | 있음 |
| 오늘 역할 | 기본 도구 | 한도 초과 시 전환 | 대안 |
| 설정 안내 | 3절 참고 | 부록 참고 | 부록 참고 |

### 무료 ChatGPT 한도 초과 시

"메시지 한도에 도달했습니다"가 나타나면 Gemini Gems로 전환합니다.

1. gemini.google.com 접속 → 왼쪽 메뉴 **"Gems"** → **"새 Gem 만들기"**
2. `Gems용_수업설계조언자_시스템지침` 내용을 지침 칸에 붙여넣기
3. `Layer_2_수업설계조언자` 파일을 소스로 업로드
4. ChatGPT에서 나눴던 Layer 2 대화 내용을 복사해 새 대화에 붙여넣고 이어가기

## 3. 내 수업 조언자 만들기

### ChatGPT 프로젝트 설정하기

**1단계. 프로젝트 만들기**

chatgpt.com 접속 → 왼쪽 메뉴 **"프로젝트"** → **"새 프로젝트"**\
프로젝트 이름 입력 (예: "수업 설계 조언자", "○○교과 수업 조언자")

**2단계. Layer 1 지침 붙여넣기**

프로젝트 설정 → **"지침"** 칸 클릭 → `ChatGPT용_수업설계조언자_프로젝트지침` 전체 내용 복사·붙여넣기 → 저장

**3단계. Layer 2 파일 업로드**

프로젝트 설정 → **"파일"** 또는 **"소스 추가"** → `Layer_2_수업설계조언자` 파일 업로드 → 저장

**4단계. 첫 대화 시작**

프로젝트 안에서 새 채팅 시작 → 조언자가 Layer 2 파일을 읽고 구성 대화를 시작합니다.

### Layer 2 구성 대화

첫 메시지를 보내면 조언자가 질문을 시작합니다. 준비 카드를 보면서 답변하세요.

조언자가 묻는 항목:

- **역할 설정**: 내 수업 철학, 조언자에게 기대하는 역할, 피하고 싶은 방식
- **교사 프로필**: 교과, 학교급·학년, 교직 경력
- **학급 맥락**: 학생 수준·특성, 특별히 고려할 사항
- **운영 여건**: 시수, 교실 환경, 활용 가능한 도구
- **기준 문서**: 교육과정, 성취기준, 내가 쓴 단원 설계 등

> **팁**: 모든 항목을 한 번에 완성하려 하지 않아도 됩니다.
> 오늘은 시작만 해도 충분합니다. 이후 대화를 거치며 자연스럽게 채워집니다.

## 4. 조언자 써보기

Layer 2 구성이 어느 정도 이루어지면 실제 수업 고민을 넣어봅니다.

### 테스트 질문 예시

**수업 설계 피드백 요청**

> "다음 주에 [단원명]을 가르칠 예정입니다. 지금 생각하는 흐름이 \_\_\_인데, 놓친 부분이 있는지 봐주세요."

**활동 아이디어 요청**

> "[성취기준]을 다루는데 학생들이 직접 참여하는 활동을 설계하고 싶어요. 어떤 방식이 있을까요?"

**점검 요청**

> "이번 단원 목표, 활동, 평가가 잘 연결되어 있는지 확인해주세요."

**자료 초안 요청**

> "[주제] 관련 학생 활동지 초안을 만들어주세요."

### 조언자 응답을 볼 때 확인할 것

- 내 교과·학급 맥락이 반영되어 있는가
- 단순한 아이디어 나열이 아니라 질문으로 내 생각을 이끌어내는가
- 내가 정한 원칙과 다른 방향을 제안할 때 명시적으로 알려주는가

## 5. AI로 수업 도구 만들기

### 두 가지 AI 사용 방식

AI를 사용하는 방법은 크게 두 가지입니다.

| 구분 | 웹 기반 AI | 로컬 설치 AI |
|:-----|:----------|:------------|
| 대표 도구 | ChatGPT, Gemini, Claude | Claude Code, Codex |
| 파일 생성 | 화면 출력 후 직접 복사·저장 | 내 컴퓨터에 자동 생성 |
| 설치 여부 | 불필요 | 필요 (터미널 사용) |
| 기술 난이도 | 낮음 | 중간 |
| 주요 용도 | 텍스트·조언·대화 | 파일·웹앱 제작 |

**오늘 시연**: 로컬 AI(Claude Code)로 만든 수업 도구 웹앱을 보여드립니다.\
**오늘 실습**: 웹 기반 AI(ChatGPT)에서 직접 웹앱을 요청해봅니다.

로컬 설치 AI는 오늘 이후 관심 있는 분이 도전해볼 수 있는 영역입니다. 오늘은 개념만 알아두는 수준으로 충분합니다.

---

### 수업 도구 웹앱이 수업의 킥이 되는 이유

AI로 도구를 만드는 것 자체가 목적이 아닙니다. **학생들이 직관으로 이해하기 어려운 지점을 시각화하는 것**이 목적입니다.

> 학생들이 잘못된 직관을 갖고 있고,\
> 말로 설명하거나 숫자로 보여주는 것만으로는 그 직관이 잘 바뀌지 않을 때

**수학 수업 사례 — 표본비율과 행사 준비**

확률과 통계 수업에서 학생들이 갖는 직관:

> "참석 확률이 70%니까 70%만 준비하면 충분하지 않나요?"

이 직관은 틀렸습니다. 기댓값만큼 준비하면 약 10번 중 4번은 준비가 부족합니다. 교과서의 숫자로도 보여줄 수 있지만, 시뮬레이션을 수백 번 돌려보면서 "준비 부족" 상황이 계속 나오는 것을 직접 경험하는 것이 다릅니다.

이 웹앱의 구조:

- 슬라이더로 신청자 수 / 참석 확률 / 여유 준비 비율 조절
- 슬라이더를 움직이면 준비 부족 확률이 실시간으로 변함
- "자동 실행"으로 수백 번 반복 → 이론값과 실험값이 수렴하는 것 확인

**내 교과에서 찾아보기**

> 학생들이 틀린 직관을 갖고 오는 지점이 있나요?\
> 정지된 그림보다 움직이는 시뮬레이션이 더 효과적인 경우는?

**다른 교과 시연 앱**

- 수평 투사 운동: `https://gwondalhyeon.github.io/AI-teacher-training/webapps/horizontal-projectile/`
- 전자기 유도: `https://gwondalhyeon.github.io/AI-teacher-training/webapps/electromagnetic-induction/`

내 교과에서 학생들이 직관적으로 오해하기 쉬운 개념 하나를 골라서,

## 부록. 플랫폼별 설정 방법

### Gemini Gems에서 수업 조언자 만들기

1. gemini.google.com 접속 → 로그인
2. 왼쪽 메뉴 **"Gems"** → **"새 Gem 만들기"**
3. Gem 이름 입력 (예: "수업 설계 조언자")
4. 지침 칸: `Gems용_수업설계조언자_시스템지침` 전체 내용 붙여넣기
5. 소스 추가: `Layer_2_수업설계조언자` 파일 업로드
6. 저장 → Gem 시작

### Claude Projects에서 수업 조언자 만들기

1. claude.ai 접속 → 로그인
2. 왼쪽 메뉴 **"Projects"** → **"New project"**
3. 프로젝트 이름 입력
4. "Project instructions": `ChatGPT용_수업설계조언자_프로젝트지침` 내용 붙여넣기\
   (Claude도 동일한 지침이 작동합니다)
5. 파일 추가: `Layer_2_수업설계조언자` 업로드
6. 새 대화 시작
