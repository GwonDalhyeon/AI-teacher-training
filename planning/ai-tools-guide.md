## Block 4 — 웹 AI vs 로컬 AI (강사 설명용)

### 도입 질문

> "이 웹앱들, 어떻게 만든 것 같으세요?"

참여자 반응을 잠깐 받은 뒤 설명으로 전환.

---

### 개념: AI를 쓰는 두 가지 방식

**방식 1 — 웹 기반 AI (브라우저에서 대화)**

지금까지 사용한 방식이다. 크롬이나 엣지를 열고, ChatGPT·Gemini·Claude 사이트에 접속해서 대화한다.

- 설치 없이 바로 사용
- 어디서든 접근 (학교, 집, 스마트폰)
- AI가 텍스트나 코드를 **화면에 출력**해줌
- 결과물을 직접 복사해서 사용해야 함

**방식 2 — 로컬 설치 AI (내 컴퓨터에 직접)**

AI를 내 컴퓨터에 설치해서 사용하는 방식이다. 대화하는 것은 같지만, AI가 내 컴퓨터 파일을 **직접 읽고 수정하고 생성**할 수 있다.

- "이런 파일 만들어줘"라고 하면 파일이 내 컴퓨터에 실제로 생김
- 여러 파일을 한 번에 다룰 수 있음
- 복사-붙여넣기 없이 결과물이 완성됨
- 설치 과정이 필요하고, 터미널(검은 화면)을 사용함

비유하자면: 웹 AI는 전화로 조언을 받는 것, 로컬 AI는 조수가 옆에 앉아서 직접 타이핑해주는 것.

---

### Claude Code

Anthropic(Claude를 만든 회사)이 만든 로컬 설치 도구.

- 터미널에서 `claude` 명령어로 실행
- Claude AI와 대화하면서 내 컴퓨터 파일을 직접 작성·수정
- 오늘 보여준 웹앱들은 이 도구를 사용해 만들었음
- 설치: Node.js 설치 → `npm install -g @anthropic-ai/claude-code`
- Anthropic API 키 필요 (유료, 사용량 기반)

**시연 포인트**: 터미널에서 `claude` 실행 후 "수평 투사 운동을 보여주는 웹앱 만들어줘"라고 입력 → 파일이 생성되는 과정을 보여준다.

---

### OpenAI Codex

OpenAI(ChatGPT를 만든 회사)가 만든 로컬 설치 도구. Claude Code와 역할이 같다.

- 터미널에서 `codex` 명령어로 실행
- ChatGPT·GPT-4o와 대화하면서 내 컴퓨터 파일을 직접 작성·수정
- 설치: Node.js 설치 → `npm install -g @openai/codex`
- OpenAI API 키 필요 (유료, 사용량 기반)

---

### 비교표

| | 웹 기반 AI | Claude Code | OpenAI Codex |
|---|---|---|---|
| 사용 방식 | 브라우저 | 터미널 | 터미널 |
| 파일 직접 생성 | ✗ (복사 필요) | ✓ | ✓ |
| 설치 필요 | ✗ | ✓ | ✓ |
| 기술 난이도 | 낮음 | 중간 | 중간 |
| 비용 | 무료 플랜 있음 | API 사용량 기반 | API 사용량 기반 |
| 적합한 용도 | 텍스트 작성, 조언, 대화 | 파일·코드 생성 | 파일·코드 생성 |

### 강사 멘트 가이드

"오늘 웹앱들은 제가 Claude Code를 써서 말로 요청해서 만들었어요. '수평으로 던진 두 물체가 같은 시간에 떨어지는 장면을 버튼으로 시연하는 HTML 웹앱을 만들어줘'라고 하면 HTML 파일이 컴퓨터에 바로 생겨요."

"설치하고 터미널을 써야 해서 처음엔 낯설 수 있어요. 하지만 웹 AI에서 '이런 html 파일 만들어줘'라고 해도 비슷한 결과를 얻을 수 있어요. 오늘 마지막에 직접 해보실 거예요."

"로컬 도구는 '관심 있다면 나중에' 영역이에요. 오늘은 이런 것도 있다는 걸 알고 가시면 됩니다."

### 참여자가 당장 해볼 수 있는 것 (Block 4 실습)

웹 기반 AI(ChatGPT 또는 Gemini)에서 직접 요청:

    지금 내 교과에서 학생들이 어려워하는 개념 하나를 골라서,
    슬라이더나 버튼으로 변수를 바꾸면 결과가 바뀌는 시각화 웹앱을 
    HTML 파일 하나로 만들어줘. Tailwind CSS CDN을 써줘.

이 프롬프트를 슬라이드에 표시하고, 결과로 나온 코드를 `index.html`로 저장해 열어보는 것까지 시연한다.
