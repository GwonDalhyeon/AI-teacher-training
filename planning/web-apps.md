# Web App Guidelines

## 철학

이 연수의 웹앱은 수업 도구가 아니라 **"AI로 이런 것도 만들 수 있다"는 가능성을 보여주는 시연용**이다.

참여자(교사)가 보고 나서 "내 교과에도 저런 게 있으면 좋겠다"는 감각을 얻는 것이 목표다.

## 기술 스택

- GitHub Pages에서 구동 가능한 정적 파일만 사용
- 단일 `index.html` — Tailwind CSS CDN, vanilla JS
- 외부 API 호출 없음, 백엔드 없음

## 웹앱 제작 기준

좋은 웹앱의 조건:

1. **변수 조작 → 즉각적인 시각 변화**: 슬라이더·버튼 등으로 값을 바꾸면 결과가 바로 바뀐다
2. **아하 모먼트**: 정지된 설명으로는 전달하기 어려운 개념이 움직임으로 이해된다
3. **교과 내용 밀착**: 교과서 내용을 그대로 다룬다. 교과 이름만 바꾸는 범용 도구가 아님

피해야 할 것:

- 퀴즈·OX 문제·분류 게임 형태 (단순 상호작용, 교과 내용 이해와 직결 안 됨)
- 정보 나열·비교표 수준 (애니메이션·인터랙션 없이 텍스트만)
- 입력받아 텍스트 출력하는 형태 (AI 챗봇 흉내)

## 교과별 주제 목록

### 통합과학1

| 주제 | 핵심 인터랙션 | 아하 모먼트 |
|------|--------------|------------|
| 원소 스펙트럼 | 원소 선택 → 방출 스펙트럼 선 표시 | 원소마다 선 위치가 고유한 지문처럼 다름 |
| 분자 결합 모양 | 비공유 전자쌍 수 조절 → 분자 모양 변화 | 전자쌍 반발로 모양이 결정되는 원리 |
| DNA 이중 나선 염기 쌍 | 염기 드래그 → 상보 결합 성립 여부 표시 | A-T, G-C만 결합하는 상보성 체험 |
| 수평 투사 운동 | 초기 속력 슬라이더 → 궤적 애니메이션 | 수평·수직 운동의 독립성, 속력과 도달 거리 |
| N형/P형 반도체 | 불순물 원소 선택 → 전하 운반체 시각화 | 도핑 종류에 따라 전자/양공 분포 변화 (**비교표 형태 지양**) |

### 통합과학2

| 주제 | 핵심 인터랙션 | 아하 모먼트 |
|------|--------------|------------|
| 전자기 유도 | 자석 이동 방향·속도 슬라이더 → 유도 전류 방향·세기 | 자속 변화율이 전류를 만든다는 것을 눈으로 확인 |
| 빛의 굴절·반사 | 입사각 슬라이더 → 굴절각·반사각 실시간 변화 | 스넬 법칙이 각도 변화로 즉각 드러남, 전반사 임계각 체험 |
| 파동과 소리 | 진동수·진폭 슬라이더 → 파형 실시간 변화 | 진동수가 높이, 진폭이 크기를 결정한다는 것을 파형으로 확인 |

### 통합사회 (후보 — 교과서 검토 후 확정)

| 주제 | 핵심 인터랙션 | 아하 모먼트 |
|------|--------------|------------|
| 수요·공급 곡선 | 곡선 이동 → 균형 가격·거래량 변화 | 외부 요인이 균형점을 어떻게 움직이는지 |
| 기후 변화 지표 | 연도 슬라이더 → 기온·해수면 수치 변화 | 수십 년 데이터가 하나의 추세선으로 수렴 |

## 연수에서의 활용 방식

- 강사가 2–3개를 **시연**하며 "이게 AI한테 말로 만들어 달라고 한 결과"임을 보여준다
- 시간이 있으면 참여자가 직접 ChatGPT에 유사한 웹앱을 요청해보는 실습으로 이어진다
- 수학 웹앱은 `math-webapps` 프로젝트에서 별도 제작, 이 연수 webapps 폴더에 포함하지 않는다
