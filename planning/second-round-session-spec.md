## 1. 이 문서의 역할

이 문서는 2026년 교원자율기획 직무연수 2기 기획안과 강사소개서를 작성하면서
확정한 내용을 기록한다. 이후 기획안 수정, 강사 역할 배정, 강의자료 제작에서는 이 문서와
`second-round-training-baseline.md`를 기준으로 삼는다.

개인 연락처와 서명 등 개인정보는 이 Markdown 문서에 기록하지 않는다. 제출용 HWPX와
PDF는 저장소 밖의 `../AI_Workspace/projects/AI-teacher-training/기획안/`에서만 관리한다.

## 2. 확정된 과정 개요

- 과정명: **로컬 AI로 다시 만드는 수학 수업자료: 웹 학습도구와 탐구 학습지**
- 영역: 교수학습
- 대상: 중등 수학교사
- 시수: 총 12시간
- 운영일: 2026. 11. 7.(토), 2026. 11. 14.(토)
- 운영시간: 각 09:00~16:00, 하루 6시간
- 장소: 경상남도교육청 교육연수원 나눔관 우선 검토
- 운영방식: 설명보다 직접 실습과 결과물 제작 중심
- 강사: 권달현, 이동언
- 보조강사: 없음으로 작성

기획자는 경상국립대학교사범대학부설고등학교 교사 권달현으로 기록한다.

## 3. 과정의 핵심 정의

교사가 보유한 HWPX·PDF·MS Office 교수학습자료를 내 컴퓨터의 파일을 직접 다루는
생성형 AI로 분석·재구성하고, 자료 속 수학 개념을 조작 가능한 웹 학습도구로
구현·검증·배포한 뒤 학생 탐구 학습지와 연결하는 12시간 실습형 연수로 구성한다.

특정 AI 서비스를 필수 도구로 고정하지 않는다. 연수생은 Codex, Claude Code,
Antigravity 등 자신이 사용할 수 있는 서비스를 선택한다. 제품별 기능보다 작업 폴더,
프로젝트 설명, 제작 계획서, 파일 읽기·수정, 명령 실행, 오류 수정, 결과 검토와 같은
공통 작업 방식을 가르친다.

## 4. 1기 선정 과정과의 차별성

1기 과정은 생성형 AI와의 대화, 수업 설계 조언자 구성, 명세서 작성과 바이브코딩
체험이 중심이었다. 2기 과정은 다음 차이를 명확히 드러낸다.

- 교사가 실제로 사용하던 HWPX·PDF 수업자료에서 출발한다.
- 여러 교과의 수업 설계보다 중등 수학 개념의 조작과 시각화에 집중한다.
- 웹 학습도구 제작을 마지막 체험이 아니라 전체 12시간을 관통하는 프로젝트로 삼는다.
- 제작한 웹 학습도구를 학생이 접속할 수 있는 주소로 실제 배포한다.
- 웹 학습도구와 예상–조작–관찰–설명 구조의 탐구 학습지를 함께 완성한다.
- Markdown 원본을 PDF·HWPX 등 학교 현장에서 사용할 수 있는 형식으로 출력한다.

심사위원에게는 기술 용어의 나열보다 기존 자료 분석, 수학 학습도구 제작, 정확성 검토,
학생 배포, 탐구 학습지 완성이라는 교육 활동과 결과를 중심으로 설명한다.

## 6. 참여자 최종 산출물

참여자는 다음 결과물을 하나의 수업자료 묶음으로 완성한다.

1. 정리·변환된 기존 수업자료
2. 웹 학습도구 제작 계획서
3. 조작 가능한 수학 웹 학습도구
4. 학생 접속용 공개 주소
5. 웹 학습도구와 연계된 Markdown 탐구 학습지
6. PDF 또는 HWPX 학습지 출력본
7. 수업 목적과 사용법을 설명하는 README

## 7. 문서 처리와 공개 원칙

- HWP·HWPX·PDF·XLSX·DOCX·이미지 읽기와 Markdown 변환은 `kordoc`을 기준으로 한다.
- 기존 HWPX 서식을 보존하는 정밀 편집은 `python-hwpx` 또는 HWPX 전용 도구를 사용한다.
- 한 파일에는 한 편집 도구를 적용하고, 결과 파일을 다시 열어 확인한다.
- PDF를 Markdown으로 변환한 뒤 다시 PDF로 만들어도 원래 조판이 복원되는 것은 아님을 설명한다.
- 원본은 덮어쓰지 않고 원본, 작업용 Markdown, 새 출력 파일을 분리한다.
- 저작권 자료와 개인정보 자료는 비공개 폴더에 보관하고 공개 저장소에 올리지 않는다.
- 공개 저장소에는 직접 제작한 웹앱과 공개 가능한 학습지만 올린다.
- 웹앱의 수학 내용, 계산, 그래프, 수식과 도형은 교사가 직접 검증한다.
