# Training Context

## 연수 위치와 브리지 조건

이 3시간 강의는 12시간 연수의 두 번째 블록이다.

    [앞 강의 3h] ──────► [이 강의 3h] ──────► [뒤 강의 6h]
     다른 강사             권달현 (수학)           다른 강사
     AI 활용 개론          ← 이 프로젝트 →         AI 수업 준비·활용 심화

**브리지 조건**: 뒤 강사는 참여자들이 자신의 ChatGPT 수업 설계 조언자 프로젝트를
갖고 있다는 전제로 6시간을 진행한다.
→ 이 3시간이 끝날 때 모든 참여자의 프로젝트가 실제로 작동하는 상태여야 한다.

---

## 3시간 강의 구성 (총 180분)

### Block 1 — 도입·개념 (0–25분, 25분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 0–5분 | **오프닝**: 오늘 하루 전체 흐름(앞 3h / 이 3h / 뒤 6h) 안내, 이 시간이 끝날 때 손에 쥐게 될 것 | 설명 |
| 5–15분 | **수업 조언자 vs 일반 AI 채팅**: 프로젝트 기능의 의미, 지침·파일·맥락이 유지되는 방식 | 설명·시연 |
| 15–25분 | **Layer 구조 소개**: Layer 1(조언자의 행동 원칙, 이미 완성됨)과 Layer 2(내 맥락 계약, 오늘 함께 만들 것)의 차이 | 설명 |

---

### Block 2 — 내 조언자 만들기 (25–80분, 55분) ⛔ 절대 생략 불가

| 시간 | 내용 | 유형 |
|------|------|------|
| 25–30분 | **AI 플랫폼 안내**: ChatGPT(기본) / Gemini Gems(한도 초과 시) / Claude Projects(대안) 비교, 무료 한도 초과 시 전환 절차 | 설명 |
| 30–37분 | **미니 활동지** (강의록에 삽입, 별도 파일 없음): 4항목 단답형, Layer 2 대화 전 내 정보 정리 | 실습 |
| 37–45분 | **프로젝트 지침 설정**: ChatGPT 프로젝트 생성 → Layer 1 지침 파일 열기 → 프로젝트 지침 칸에 전체 붙여넣기 → 저장 확인 | 시연+실습 |
| 45–50분 | **Layer 2 소스 연결**: Layer 2 파일 업로드 → 프로젝트 안에서 새 대화 시작 준비 | 시연+실습 |
| 50–80분 | **Layer 2 구성 대화**: 조언자가 질문, 참여자가 답변하며 맥락 계약 작성 시작 | 실습 |

> **절대 유지할 핵심 과정**: 참여자가 직접 ChatGPT 프로젝트를 만들고, `ChatGPT용_수업설계조언자_프로젝트지침.md`의 내용을 프로젝트 지침 칸에 붙여넣어 저장하는 과정은 생략하지 않는다. 이 과정이 끝나야 뒤 강의에서 사용할 "살아있는 수업 설계 조언자"가 만들어진다.

**미니 활동지 내용** (강의록 본문에 박스로 삽입):

    ┌─────────────────────────────────────────────────────┐
    │  내 수업 조언자 준비 카드                            │
    │                                                     │
    │  교과:                    학교급·학년:               │
    │  자주 하는 수업 관련 작업 (1~2가지):                  │
    │                                                     │
    │  AI에게 도움받고 싶은 것 (1가지):                     │
    │                                                     │
    │  내 수업에서 AI가 하지 않았으면 하는 것 (1가지):        │
    └─────────────────────────────────────────────────────┘

---

### Block 3 — 조언자 테스트 (80–105분, 25분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 80–95분 | **실전 테스트**: 내 실제 수업 고민을 조언자에게 입력, 결과 관찰 | 실습 |
| 95–105분 | **결과 공유**: 2~3명이 질문과 조언자 응답을 화면으로 공유, 다른 교과와 비교 | 공유 |

> ⏩ 시간 부족 시: 공유 생략, 개인 실습만

---

### Block 4 — AI로 수업 도구 만들기 (105–160분, 55분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 105–112분 | **웹 AI vs 로컬 AI**: 두 가지 사용 방식의 차이 — Claude Code·Codex 개념 소개 | 설명 |
| 112–124분 | **강사 수학 수업 사례**: 표본비율 앱 시연 + 수업 설계 의도("기댓값만큼 준비하면 충분하다"는 직관을 왜, 어떻게 깨는가) | 시연·설명 |
| 124–128분 | **웹앱 갤러리 소개**: 연수 시연용 웹앱 구성 페이지를 열고 자연과학·사회·법 계열 사례를 한눈에 보여주기 | 시연 |
| 128–145분 | **대표 사례 3개 압축 시연**: 자연과학 1개 + 도시·사회 1개 + 법 1개를 "깨야 할 직관 → 조작 → 아하 모먼트" 구조로 시연 | 시연 |
| 145–153분 | **내 교과 아이디어 스케치**: 참여자가 자기 교과의 오개념·직관, 조작 변수, 보이는 결과를 3줄로 정리 | 실습 |
| 153–160분 | **직접 요청 실습**: 오늘 만든 조언자 또는 ChatGPT에 자기 교과 웹앱 요청, 결과 확인 | 실습 |

> ⏩ 시간 부족 시:
> 1. 직접 요청 실습 생략 → 아이디어 스케치만 하고 마무리
> 2. 대표 사례 3개 → 1개만 시연
> 3. 웹앱 갤러리 소개는 목록 페이지를 1분만 보여주기
> 4. 로컬 AI 설명 단축 (7분 → 3분)
>
> **수학 수업 사례 시연은 Block 4의 핵심. 다른 것을 줄여도 이것은 유지한다.**

---

### Block 5 — 마무리 (160–175분, 15분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 160–165분 | **내 조언자 점검**: 조언자에게 질문 하나 더, 작동하는지 본인이 직접 확인 | 실습 |
| 165–175분 | **뒤 강의 예고**: "이 조언자를 가지고 뒤 강사와 무엇을 할지" — 뒤 강의와 연결되는 지점 안내 | 정리 |

여유 시간: 5분

## 생략 우선순위 (전체)

시간이 부족할 때 아래 순서로 줄인다.

| 우선순위 | 생략 대상 | 대체 방법 |
|---------|-----------|-----------|
| 1 | Block 4 직접 요청 실습 | 아이디어 스케치만 하고 마무리 |
| 2 | Block 4 대표 사례 3개 → 1개 | 웹앱 갤러리 URL만 안내 |
| 3 | Block 3 결과 공유 | 개인 실습만 진행 |
| 4 | Block 4 로컬 AI 설명 단축 (7분 → 3분) | 한 슬라이드로 압축 |
| 5 | Block 5 단축 (15분 → 5분) | 조언자 점검 생략 |

**절대 생략 불가**: Block 2 전체 (25–80분)
**Block 2 생략 금지**: 프로젝트 생성, Layer 1 프로젝트 지침 붙여넣기, Layer 2 파일 업로드
**Block 4 생략 금지**: 수학 수업 사례 시연 (112–124분)
