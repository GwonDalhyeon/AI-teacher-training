# Training Context

## 연수 위치와 브리지 조건

이 3시간 강의는 12시간 연수의 두 번째 블록이다.

- 앞 강의(3h): AI 활용 개론 — 다른 강사
- **이 강의(3h): ChatGPT 수업 조언자 만들기 — 이 프로젝트**
- 뒤 강의(6h): AI 수업 준비·활용 심화 — 다른 강사

뒤 강사는 참여자들이 이미 자신의 ChatGPT 수업 설계 조언자 프로젝트를 갖고 있다는 전제로 6시간을 진행한다. 따라서 이 3시간이 끝날 때 모든 참여자의 프로젝트가 실제로 작동하는 상태여야 한다. 이 조건은 시간 배분과 생략 가능 여부의 기준이 된다.

## 3시간 흐름 (확정안)

### Block 1 — 도입 (25분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 0–5분 | 오프닝: 오늘 하루 구조(앞 3h / 이 3h / 뒤 6h), 이 시간에 만들 것 | 설명 |
| 5–15분 | "수업 조언자"가 일반 AI 채팅과 다른 점 — 프로젝트 기능의 의미 | 설명·시연 |
| 15–25분 | Layer 구조 개요: Layer 1(조언자의 행동 원칙) vs Layer 2(내 맥락 계약) | 설명 |

### Block 2 — 내 조언자 만들기 (50분) ⛔ 생략 불가

| 시간 | 내용 | 유형 |
|------|------|------|
| 25–35분 | **미니 활동지 (1페이지)**: 교과·학급·고민 4항목 — Layer 2 준비용 | 실습 |
| 35–45분 | ChatGPT 프로젝트 생성 + Layer 1 지침 붙여넣기 | 시연+실습 |
| 45–50분 | Layer 2 파일 업로드 | 실습 |
| 50–75분 | 조언자와 대화: Layer 2 구성 시작 (조언자 질문 → 교사 답변) | 실습 |

### Block 3 — AI 도구 안내 + 조언자 테스트 (40분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 75–85분 | **AI 도구 안내**: ChatGPT / Gemini Gems / Claude Projects 비교, 무료 한도 시 전환법 | 설명 |
| 85–115분 | 조언자 테스트: 내 수업 고민 실제로 넣어보기 + 2~3명 결과 공유 | 실습·공유 |

### Block 4 — AI로 수업 도구 만들기 (45분)

| 시간 | 내용 | 유형 |
|------|------|------|
| 115–130분 | **웹 AI vs 로컬 AI**: 이 웹앱들이 어떻게 만들어졌는가 — Claude Code·Codex 개념 소개 | 설명·시연 |
| 130–150분 | 웹앱 시연 2개 (교과별 시각화) | 시연 |
| 150–160분 | 직접 ChatGPT에 웹앱 요청해보기 | 실습 |

> ⏩ 시간 부족 시: 직접 실습 생략 → 웹앱 1개 → Block 4 도입 5분으로 압축 순으로 축소

### Block 5 — 마무리 (10분)

| 시간 | 내용 |
|------|------|
| 160–165분 | 오늘 만든 것 확인: 내 조언자가 작동하는지 직접 확인 |
| 165–180분 | 뒤 강의(6h) 예고: "이 조언자를 가지고 무엇을 할지" |

## 미니 활동지 (Block 2, 1페이지 삽입)

강의록 안에 포함. 별도 파일 불필요. 단답형 4항목, 5분 완성.

    내 수업 조언자 준비 카드
    ─────────────────────────────────────────
    교과:               학교급·학년:
    자주 하는 수업 관련 작업 (1~2가지):
    AI에게 도움받고 싶은 것 (1가지):
    내 수업에서 AI가 하지 않았으면 하는 것 (1가지):

이 카드를 보면서 Layer 2 구성 대화를 진행한다.

## 생략 우선순위

시간이 부족할 때 아래 순서로 줄인다.

1. Block 4 직접 실습 생략 → 시연으로 대체
2. Block 4 웹앱 2개 → 1개
3. Block 4 도입(웹 vs 로컬 설명) 15분 → 5분으로 압축
4. Block 3 결과 공유 시간 단축
5. 미니 활동지 → 구두로 대체

**절대 생략 불가**: Block 2 전체 (25–75분)
