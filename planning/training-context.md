# Training Context

## 연수 위치와 브리지 조건

이 3시간 강의는 12시간 연수의 두 번째 블록이다.

- 앞 강의(3h): AI 활용 개론 — 다른 강사
- **이 강의(3h): ChatGPT 수업 조언자 만들기 — 이 프로젝트**
- 뒤 강의(6h): AI 수업 준비·활용 심화 — 다른 강사

뒤 강사는 참여자들이 이미 자신의 ChatGPT 수업 설계 조언자 프로젝트를 갖고 있다는 전제로 6시간을 진행한다. 따라서 이 3시간이 끝날 때 모든 참여자의 프로젝트가 실제로 작동하는 상태여야 한다. 이 조건은 시간 배분과 생략 가능 여부의 기준이 된다.

## 3시간 흐름 초안

| 시간 | 블록 | 유형 | 비고 |
|------|------|------|------|
| 0–10분 | 오프닝 — 오늘 12시간의 흐름, 이 시간의 목표 | 설명 | |
| 10–30분 | 수업 조언자란? Layer 1·2 구조 개요 | 설명·시연 | |
| 30–45분 | 두 지침 파일 살펴보기 (구조 이해) | 설명·시연 | |
| 45–85분 | **핵심 실습**: 프로젝트 만들고 Layer 2 구성 시작 | 실습 | 필수, 생략 불가 |
| 85–105분 | 조언자 테스트 — 내 교과 수업 고민 넣어보기 | 실습 | |
| 105–120분 | 교사용 활동지 작성 | 실습 | ⏩ 시간 부족 시 숙제로 전환 |
| 120–155분 | 웹앱 시연 — AI로 수업 도구 만들기 (2–3개) | 시연 | ⏩ 시간 부족 시 1개로 축소 |
| 155–170분 | 웹앱 직접 요청해보기 | 실습 | ⏩ 시간 부족 시 시연으로 대체 |
| 170–180분 | 정리 + 뒤 강의 예고 | 정리 | |

## 생략 우선순위

시간이 부족할 때 아래 순서로 줄인다.

1. 웹앱 직접 실습 → 시연으로 대체
2. 웹앱 시연 개수 → 2개 → 1개
3. 활동지 → 숙제로 전환
4. 조언자 테스트 시간 단축

**절대 생략 불가**: 프로젝트 만들기 + Layer 2 구성 시작 (45–85분 블록)
