# 산출물 제작 계획

## 1단계: 연수 전체 구조 확정

- 원본 원고의 핵심 흐름 정리
- 3시간 시간표 설계
- 직접 실습과 강사 시연의 분기안 작성
- 교과 공통 적용 원칙 정리

결과물: `lecture/수정_강의록.md`

## 2단계: 교사용 활동지 제작

- 내 수업 조언자 목표 정하기
- ChatGPT 프로젝트 이름 정하기
- 내 수업 맥락 입력하기
- 수업 조언자 테스트 질문 만들기
- 웹앱 아이디어 스케치하기

결과물: `worksheets/교사용_활동지.md`

## 3단계: PPT 원고 제작

- 슬라이드 제목과 핵심 문장 작성
- 강사 멘트 작성
- 시연 화면과 실습 안내 표시
- 시간이 부족할 때 생략 가능한 슬라이드 구분

결과물: `slides/PPT_원고.md`

## 4단계: 프로젝트 지침과 실습 프롬프트 정리

- 연수 준비 프로젝트 지침
- 참여자용 수업 조언자 프로젝트 지침
- 수업 맥락 입력 양식
- 테스트 질문 모음
- 웹앱 제작 요청 프롬프트

결과물: `prompts/`

## 5단계: 웹앱 예시 제작

- 목표-활동-평가 연결 점검기
- 수업 질문 생성기
- 루브릭 초안 생성기
- 수업 조언자 맥락 카드 생성기

결과물: `webapps/`
