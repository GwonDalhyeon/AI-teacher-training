## 웹앱 (`webapps/*/index.html`)

- 단일 `index.html`, Tailwind CSS CDN, vanilla JS, 백엔드 없음
- 인터랙션: 슬라이더·버튼 입력 → 즉각적인 시각 변화
- 제작 기준 및 주제 목록: `planning/web-apps.md` 참조

## 공통 원칙

- 강사 설명 / 시연 / 참여자 실습 / 정리를 항상 구분
- 생략 가능한 부분은 반드시 ⏩ 표시로 명시
- 특정 교과 예시를 쓸 때는 다른 교과로 전이 가능하도록 구성
- 개인정보·학생 정보·저작권 주의 사항이 필요한 맥락에는 반드시 포함
