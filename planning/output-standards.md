# Output Standards

## 문서 구조

연수 관련 문서는 세 파일로 관리한다. 연수자 자료를 기준으로 나머지 두 파일이 파생된다.

| 파일 | 대상 | 방식 |
|------|------|------|
| `lecture/연수자_자료.md` | 참여자 | 개념·절차·활동지·참고자료 |
| `slides/PPT_원고.md` | 강사 제작용 | 슬라이드 번호가 연수자 자료 섹션과 연동 |
| `lecture/강사용_원고.md` | 강사 | 연수자 자료 전체 + `[강사 메모]` 블록 삽입 |

`worksheets/교사용_활동지.md`의 미니 활동지는 `lecture/연수자_자료.md` 안에 통합됨.

---

## 연수자 자료 (`lecture/연수자_자료.md`)

참여자가 연수 중 보고 연수 후 가져가는 문서.

- 강사 멘트, 시간 큐, 생략 조건 포함하지 않음
- 각 섹션은 독립적으로 읽을 수 있게 작성
- 단계별 절차는 번호 목록, 개념 비교는 표, 중요 활동은 박스

섹션 구조:

    0. 오늘 연수에 대하여
    1. 수업 조언자란?
    2. 내 AI 선택하기
    3. 내 수업 조언자 만들기  ← 미니 활동지 포함
    4. 조언자 써보기
    5. AI로 수업 도구 만들기
    부록. 플랫폼별 설정 방법

## PPT 원고 (`slides/PPT_원고.md`)

슬라이드 블록 형식:

    ---
    슬라이드 번호: S01
    섹션: 0 (도입)
    슬라이드 제목:
    화면 핵심 문장/요소:
    강사 멘트:
    시연 또는 활동:
    예상 소요 시간:

슬라이드 번호는 S01, S02… 형식. 섹션 번호는 연수자 자료 섹션과 일치시킨다.

---

## 강사용 원고 (`lecture/강사용_원고.md`)

연수자 자료 전체를 포함하되, 강사 전용 정보를 블록으로 삽입한다.

`[강사 메모]` 블록 형식:

    > **[강사 메모]**
    > 여기서 참여자 화면을 확인한다. 프로젝트가 생성되지 않은 사람은 개별 도움.
    > 시간 부족 시: Layer 2 대화를 10분으로 줄이고 이후 혼자 이어가도록 안내.

삽입 위치: 연수자 자료의 각 활동 직전 또는 직후.
내용: 강사 멘트 세부 사항, 시연 절차, 시간 조정 지침, 참여자 어려움 대처법.

## 웹앱 (`webapps/*/index.html`)

- 단일 `index.html`, Tailwind CSS CDN, vanilla JS, 백엔드 없음
- 인터랙션: 슬라이더·버튼 입력 → 즉각적인 시각 변화
- 제작 기준 및 주제 목록: `planning/web-apps.md` 참조

---

## 공통 원칙

- 연수자 자료와 강사용 원고에서 특정 교과 예시를 쓸 때는 다른 교과로 전이 가능하게 구성
- 개인정보·학생 정보·저작권 주의 사항이 필요한 맥락에는 반드시 포함
- 생략 가능한 활동은 강사용 원고의 `[강사 메모]`에만 표시, 연수자 자료에는 포함하지 않음
