# 연수 시연용 웹앱 작업지시서

## 1. 작업 목적

교사 대상 3시간 연수의 Block 4에서 보여 줄 과학 시연용 웹앱 2개를 완성한다.

이 웹앱의 목적은 코딩 기술을 보여주는 것이 아니라, 교사가 "학생의 직관이 흔들리는 순간"을 웹앱으로 설계할 수 있다는 감각을 전달하는 것이다. 내용을 잘 모르는 학생이나 타교과 교사가 보아도 조작과 결과의 관계를 바로 이해할 수 있어야 한다.

배포 주소:

- 목록: `https://gwondalhyeon.github.io/AI-teacher-training/webapps/`
- 수평 투사 운동: `https://gwondalhyeon.github.io/AI-teacher-training/webapps/horizontal-projectile/`
- 전자기 유도: `https://gwondalhyeon.github.io/AI-teacher-training/webapps/electromagnetic-induction/`

## 2. 공통 제작 조건

- 대상 파일은 각각 단일 `index.html`이다.
- Tailwind CSS CDN과 vanilla JavaScript만 사용한다.
- 백엔드, 빌드 도구, 외부 API, 패키지 설치를 사용하지 않는다.
- 폴더명과 파일명은 영문으로 유지한다.
- 화면에 보이는 제목, 설명, 버튼, 관찰 문장은 한글로 작성한다.
- 데스크톱과 모바일에서 모두 주요 조작이 보이고, 텍스트가 겹치지 않아야 한다.
- 앱은 수업 시연용이므로 자유도를 높이기보다 변화가 뚜렷한 버튼과 프리셋을 우선한다.
- 수치는 보조 정보로만 사용하고, 핵심 이해는 움직임, 색, 방향, 강도 변화로 전달한다.

## 3. 공통 화면 구조

두 앱은 같은 연수 안에서 이어서 시연되므로 기본 구조를 맞춘다.

1. 상단: 교과, 앱 제목, 깨야 할 직관을 1-2문장으로 제시
2. 중앙: 큰 시각화 영역
3. 오른쪽 또는 아래: 2-4개의 시연 버튼과 결과 카드
4. 하단 또는 카드: "관찰 포인트" 한 문장

화면에 사용법을 길게 설명하지 않는다. 버튼 이름만 보고도 강사가 바로 시연할 수 있게 만든다.

## 4. 앱 1: 수평 투사 운동

대상 파일: `webapps/horizontal-projectile/index.html`

### 핵심 의도

- 교과: 통합과학1
- 깨야 할 직관: "빠르게 던지면 더 빨리 떨어질 것 같다"
- 아하 모먼트: 수평 속력이 달라도 낙하 시간은 동일하다

### 필수 동작

- 같은 높이에서 출발하는 두 공을 동시에 보여준다.
- `동시에 발사` 버튼을 누르면 두 공이 서로 다른 포물선 궤적을 그리며 움직인다.
- 느린 공과 빠른 공은 수평 이동 거리가 다르지만 같은 순간 바닥에 닿아야 한다.
- 착지 순간에는 "동시 착지"가 눈에 띄게 표시되어야 한다.
- 결과 카드에는 두 공의 낙하 시간이 같고, 수평 이동 거리만 다르다는 점을 표시한다.
- 한 공은 기준 속력으로 고정하고, 다른 공의 속력을 프리셋으로 바꾸어 비교한다.

### 조작 방식

권장 조작:

- 비교 속도 프리셋: `느림 vs 빠름`, `보통 vs 빠름`, `매우 빠름 vs 빠름`
- 실행 버튼: `동시에 발사`
- 보조 버튼: `다시 보기`

과도한 조작은 피한다.

- 중력값 조절 금지
- 발사 높이 조절 금지
- 공기저항 조절 금지
- 각도 발사 기능 추가 금지

### 시연 흐름

1. 강사가 "빠른 공이 먼저 떨어질까요?"라고 묻는다.
2. `동시에 발사`를 누른다.
3. 두 공의 궤적은 다르지만 같은 순간 착지하는 장면을 보여준다.
4. 결과 카드에서 "낙하 시간은 같고, 수평 거리만 다르다"를 확인한다.

### 완료 기준

- 애니메이션이 끊기지 않고 2-4초 안에 끝난다.
- 두 공의 착지 시점이 시각적으로 동시에 보인다.
- 모바일에서도 시각화 영역과 실행 버튼이 한 화면 흐름 안에서 자연스럽게 보인다.
- 사용자가 버튼을 여러 번 눌러도 상태가 꼬이지 않는다.

## 5. 앱 2: 전자기 유도

대상 파일: `webapps/electromagnetic-induction/index.html`

### 핵심 의도

- 교과: 통합과학2
- 깨야 할 직관: "자석이 가까이 있으면 전류가 흐를 것 같다"
- 아하 모먼트: 자석이 움직여 자기장이 변할 때만 전류가 생긴다
- 표현 초점: 오른손법칙 자체보다, 코일을 지나는 자기장 변화와 그 결과로 나타나는 전류계 반응을 함께 보여준다.

### 필수 동작

- 코일, 막대자석, 전류계를 한 화면에 크게 배치한다.
- 전류계는 필수 요소로 사용한다. 전구는 세기 변화를 보조로 강조할 때만 추가한다.
- 코일 안쪽을 지나는 자기장 선 또는 자기선속 변화를 반드시 시각화한다.
- `가까이 두기`를 누르면 자석이 코일 근처에 멈춰 있지만 전류는 0으로 표시된다.
- `천천히 넣기`를 누르면 자석이 움직이는 동안만 전류계가 약하게 흔들린다.
- `빠르게 넣기`를 누르면 자석이 움직이는 동안만 전류계가 더 크게 흔들린다.
- `빼기`를 누르면 전류계가 반대 방향으로 흔들린다.
- 자석이 멈추면 전류계는 반드시 0으로 돌아와야 한다.

### 조작 방식

필수 버튼:

- `가까이 두기`
- `천천히 넣기`
- `빠르게 넣기`
- `빼기`

과도한 조작은 피한다.

- 자석 위치를 자유 드래그로 만들지 않는다.
- 코일 감은 수, 자기장 세기, 저항값 같은 변수를 동시에 열지 않는다.
- 실제 전자기 방정식을 자세히 설명하는 계산 앱으로 만들지 않는다.

### 시연 흐름

1. 강사가 "자석을 가까이 두기만 하면 전류가 흐를까요?"라고 묻는다.
2. `가까이 두기`를 눌러 전류 0을 보여준다.
3. `천천히 넣기`, `빠르게 넣기`를 차례로 눌러 움직임의 빠르기에 따라 반응이 달라짐을 보여준다.
4. `빼기`를 눌러 방향이 바뀌면 전류계도 반대로 움직이는 것을 보여준다.

### 완료 기준

- 정지 상태와 이동 상태의 차이가 즉시 보인다.
- 코일 안 자기장이 "변화 없음 / 증가 / 빠르게 증가 / 감소" 중 무엇인지 화면에서 바로 구분된다.
- 전류계 반응의 방향과 세기 차이가 명확하다.
- 자석 이동이 끝나면 전류가 0으로 돌아온다.
- 물리를 잘 모르는 사람이 보아도 "가까움이 아니라 변화가 중요하다"는 문장을 이해할 수 있다.
